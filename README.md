# Quarterly Family Expense Budget SQL

## 📌 Project Overview

This project focuses on analyzing family household expenses and planning a quarterly budget using SQL, PostgreSQL, CSV datasets, and Excel.

The objective is to organize expense data, understand spending patterns, compare budgets across quarters, and support better financial planning.

## 🎯 Project Objectives

- Analyze household expenses and spending patterns.
- Organize expense data for SQL-based analysis.
- Prepare a budget for October, November, and December 2026.
- Compare the fourth-quarter budget with the previous quarter.
- Identify major expense categories.
- Support effective household budget planning.

## 🛠️ Tools and Technologies

- SQL
- PostgreSQL
- Microsoft Excel
- CSV datasets

## 📂 Project Files

| File Name | Description |
|---|---|
| `Real_Expense_Data_Import.csv` | Household expense data prepared for import and analysis. |
| `quarterly_budget_import.csv` | Quarterly budget data prepared for import. |
| `October_November_December_2026_Budget.xlsx` | Excel file containing the budget for October–December 2026. |
| `Q4_Budget_vs_Previous_Quarter.csv` | Data for comparing the fourth-quarter budget with the previous quarter. |
